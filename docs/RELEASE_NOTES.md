# Data Force helli 7 — Iran Open RoboCup 2026

## English

Initial public source release for Data Force helli 7, the first-place team in the Junior Soccer Simulation Secondary league at Iran Open RoboCup 2026, as reported by the team's mentor.

- School: Allameh Helli 7 High School (SAMPAD), Iran.
- Equal code contributors: MohammedHossein Ghaffary, Alireza Bashiri vasegh, Sobhan Barzegar, Mohammadhasan Heydarifar.
- Mentor: Ali Asghar Jalalieh.
- All 11 supplied Python controller files preserved without source edits.
- English and Persian README files, setup instructions, technical review notes, source checksums, and Apache-2.0 licensing with upstream attribution.
- Requires Webots, NumPy, and the official RCJ Soccer Simulator; only yellow-team controller code is bundled.

Syntax/import and representative data-path checks passed. No full Webots match was run during preparation. Known role-message and supervisor-handling findings are documented, not silently fixed. Exact final-match source identity and competition environment are not independently established by this release.

Official competition reference: https://iranopenrobocup.ir/leagues/junior-soccer-simulation-secondary
Official simulator: https://github.com/robocup-junior/rcj-soccersim

## فارسی

نخستین انتشار عمومی سورس تیم Data Force helli 7، مقام اول لیگ شبیه‌ساز فوتبالیست دانش‌آموزی پیشرفته در ایران‌اپن ۲۰۲۶، بر اساس اطلاعات منتور تیم.

- مدرسه: علامه حلی ۷ تیزهوشان.
- چهار عضو با مشارکت برابر: محمد حسین غفاری، علیرضا بشیری واثق، سبحان برزگر و محمدحسین حیدری‌فر.
- منتور: علی اصغر جلالیه.
- حفظ هر ۱۱ فایل پایتون ارسالی بدون ویرایش سورس.
- README فارسی و انگلیسی، راهنمای نصب و اجرا، یادداشت فنی، هش سورس و مجوز Apache-2.0 همراه انتساب پایه رسمی.
- نیازمند Webots، NumPy و پایه رسمی RCJ Soccer Simulator؛ بسته فقط شامل کنترلر تیم زرد است.
