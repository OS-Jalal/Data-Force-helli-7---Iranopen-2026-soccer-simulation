# راهنمای مشارکت

[فارسی](CONTRIBUTING.fa.md) | [English](CONTRIBUTING.md)

پیشنهادهایی که خوانایی، تکرارپذیری اجرا و رفتار تیم را بهتر کنند پذیرفته می‌شوند.

## گزارش مشکل

نسخه Webots، نسخه Python و NumPy، commit پایه شبیه‌ساز، نام ربات‌ها، کنترلر حریف، مراحل بازتولید و traceback مرتبط کنسول را بنویسید. رفتار مورد انتظار و رفتار رخ‌داده را توضیح دهید.

## پیشنهاد تغییر

۱. در شاخه یا fork جداگانه کار کنید.

۲. در Pull Request، مشکل و رفتار حاصل از تغییر را توضیح دهید.

۳. تغییرات نامرتبط را جدا کنید و مجوز و انتساب پایه را حفظ کنید.

۴. اگر نصب یا رفتار عوض شده، هر دو README را به‌روز کنید.

۵. برای تغییر استراتژی، تنظیمات مسابقه و نتایج چند اجرای تکراری را ثبت کنید؛ نتیجه یک بازی برای اثبات بهبود کافی نیست.

۶. هر تغییر رفتار نسبت به سورس اولیه منتشرشده را مشخص کنید.

برای بررسی نحو، از ریشه مخزن اجرا کنید:
