## محتوای این مخزن

این مخزن شامل **تمام پوشه کنترلر ارسالی برای انتشار، با ۱۱ فایل پایتون** است. فایل زمین، داور، کنترلر حریف آبی، تصاویر محیط، نرم‌افزار Webots، ضبط مسابقات و تاریخچه اصلی Git در فایل ارسالی وجود نداشتند. زیرساخت اجرا را از [مخزن رسمی RCJ Soccer Simulator](https://github.com/robocup-junior/rcj-soccersim) دریافت کنید.

سورس کنترلر، بایت‌به‌بایت مطابق فایل ارسالی حفظ شده است. این انتشار مستندات، به‌معنای تأیید یکسان‌بودن این نسخه با کد دقیق اجراشده در مسابقه فینال نیست.

## قابلیت‌های موجود در کد

- اجرای سه ربات زرد با نام‌های `Y1`، `Y2` و `Y3` از طریق یک کنترلر مشترک.
- تخصیص و جابه‌جایی پویا بین دو نقش هجومی و یک نقش دفاعی.
- برآورد موقعیت توپ با استفاده از مشاهده محلی و اطلاعات هم‌تیمی‌ها.
- پیش‌بینی موقعیت توپ و مدیریت تازگی مشاهدات مشترک.
- ارتباط JSON برای موقعیت‌ها، اطلاعات توپ، تخصیص نقش و مراحل همکاری در تله‌گذاری.
- موقعیت‌گیری، نزدیک‌شدن به توپ، دنبال‌کردن دفاعی و همکاری هجومی.
- پایش میزان حرکت ربات‌ها و توپ.
- توقف موتورهای ربات در چرخه دارای خطا و گزارش traceback با محدودیت دفعات چاپ.

این موارد از روی سورس شناسایی شده‌اند و ادعای عملکرد اندازه‌گیری‌شده نیستند. مدل یادگیری ماشین یا خط آموزش مدل در بسته وجود ندارد.

## پیش‌نیازها و سازگاری

| مؤلفه | نیاز / وضعیت |
| ---: | ---: |
| پایتون | Python 3 نسخه ۶۴ بیتی، تنظیم‌شده در Webots |
| Webots | مستندات پایه رسمی فعلاً R2025a را معرفی می‌کند؛ نسخه دقیق استفاده‌شده توسط تیم اعلام نشده است |
| کتابخانه پایتون | NumPy، مورد استفاده در فایل‌های حمله و دفاع |
| رابط شبیه‌ساز | ماژول `controller` از خود Webots؛ بسته‌ای هم‌نام از PyPI نصب نکنید |
| پایه اجرا | RCJ Soccer Simulator؛ در صورت دسترسی، همان نسخه اصلی مسابقه استفاده شود |
| رنگ پشتیبانی‌شده | فقط زرد؛ ربات‌های `Y1`، `Y2` و `Y3` |

فایل قفل وابستگی‌ها و نسخه دقیق Python و NumPy مسابقه ارائه نشده است. به همین دلیل، در `requirements.txt` فقط وابستگی واقعی ثبت شده و شماره نسخه ساختگی تعیین نشده است. نسخه پایه معرفی‌شده در ادامه، مرجع بررسی راهنماست و نسخه تأییدشده مسابقه نیست.

### ۳. قراردادن کنترلر تیم

۱. از پوشه فعلی `controllers/rcj_soccer_team_yellow/` در پایه شبیه‌ساز، بیرون از پوشه شبیه‌ساز پشتیبان بگیرید.

۲. کل آن پوشه را با پوشه `rcj_soccer_team_yellow/` موجود در این مخزن جایگزین کنید.

۳. هر ۱۱ فایل پایتون را با هم کپی کنید؛ فایل اصلی به فایل‌های دیگر وابسته است.

۴. نام پوشه و نام فایل ورودی را تغییر ندهید: پوشه `rcj_soccer_team_yellow` و فایل `rcj_soccer_team_yellow.py`.

| مسیر در پایه شبیه‌ساز | منبع |
| ---: | ---: |
| `worlds/soccer.wbt` | پایه رسمی |
| `controllers/rcj_soccer_referee_supervisor/` | پایه رسمی |
| `controllers/rcj_soccer_team_blue/` | پایه رسمی یا حریف انتخابی |
| `controllers/rcj_soccer_team_yellow/` | پوشه کامل کد این تیم |

### ۴. اجرای مسابقه در Webots

۱. Webots را نصب و باز کنید.

۲. از مسیر **Tools → Preferences → Python command**، پایتون مرحله قبل را انتخاب کنید. عنوان منو ممکن است بین سیستم‌عامل‌ها متفاوت باشد.

۳. از **File → Open World**، فایل `worlds/soccer.wbt` در پوشه پایه شبیه‌ساز را باز کنید.

۴. نام ربات‌های زرد باید `Y1`، `Y2` و `Y3` باشد و مقدار فیلد `controller` آن‌ها `rcj_soccer_team_yellow` باشد. جهان رسمی بررسی‌شده همین نام‌گذاری را دارد.

۵. کنترلر داور رسمی و کنترلر تیم آبی را در دسترس نگه دارید.

۶. شبیه‌سازی را شروع و کنسول Webots را برای خطاهای import و خطاهای کنترلر بررسی کنید.

در صورت نصب Webots و در دسترس بودن دستور آن در PATH، از پوشه پایه شبیه‌ساز می‌توان اجرا کرد:

</div>

<div dir="ltr" align="left">

```bash
webots --mode=run worlds/soccer.wbt
```

</div>

<div dir="rtl" align="right">

فایل کنترلر را با `python rcj_soccer_team_yellow.py` به‌صورت مستقل اجرا نکنید؛ کنترلر به شروع شبیه‌سازی و تجهیزات ربات در Webots وابسته است.

## معرفی فایل‌ها

همه فایل‌های زیر داخل پوشه `rcj_soccer_team_yellow/` هستند.

| فایل | کاربرد |
| ---: | ---: |
| `rcj_soccer_team_yellow.py` | ساخت Robot و شروع MyRobot |
| `my_robot.py` | حلقه کنترل، پیام‌ها، اجرای نقش‌ها و مدیریت خطا |
| `data.py` | داده محلی و مشترک، مختصات، تازگی داده و پیش‌بینی توپ |
| `roles.py` | تخصیص و تغییر نقش‌های ربات‌ها |
| `offense1_yellow.py` | استراتژی هجومی اول |
| `offense2_yellow.py` | استراتژی هجومی دوم |
| `defense_yellow.py` | رفتار و موقعیت‌گیری دفاعی |
| `progress.py` | پایش حرکت ربات‌ها و توپ |
| `rcj_soccer_robot.py` | رابط مبتنی بر پایه رسمی برای تجهیزات و پیام‌ها |
| `rcj_soccer_robot_compat.py` | سازگاری پیام تیم و توابع جهت‌یابی |
| `utils.py` | تابع کمکی تشخیص جهت |

قالب پیام‌ها، ثابت‌های مهم و یافته‌های بررسی سورس در [یادداشت فنی فارسی](docs/TECHNICAL.fa.md) و [نسخه انگلیسی](docs/TECHNICAL.md) آمده‌اند.

## رفع خطاهای متداول

| مشکل | بررسی پیشنهادی |
| ---: | ---: |
| نبودن ماژول NumPy | وابستگی را با همان پایتون تنظیم‌شده در Webots نصب کنید |

| نبودن زمین یا داور | پایه رسمی را جداگانه دریافت کنید |
| توقف موتور همراه traceback | اولین خطای کنسول و یادداشت‌های فنی را بررسی کنید |

## بررسی انجام‌شده و محدودیت‌ها

هر ۱۱ فایل از نظر نحو پایتون بررسی شدند؛ ماژول‌های محلی import و چند مسیر نمونه پیام و داده بیرون از Webots بررسی شدند. همچنین فایل‌های سورس با آرشیو ارسالی تطبیق بایتی داده شدند.

**در محیط آماده‌سازی، مسابقه کامل Webots اجرا نشده است.** این بررسی‌ها به‌تنهایی عملکرد مسابقه، صحت تمام رفتارها، بازتولید دقیق مسابقه یا سازگاری با همه نسخه‌های پایه را اثبات نمی‌کنند. یافته‌های بررسی در [یادداشت فنی](docs/TECHNICAL.fa.md) ثبت شده‌اند و سورس اصلی بدون اعلام تغییر داده نشده است.
